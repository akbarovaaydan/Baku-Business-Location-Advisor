# Baku Business Location Advisor

An AI-assisted business location recommendation project focused on Baku, Azerbaijan.

## About the Project

AI Business Location Advisor helps users identify suitable locations for different types of businesses by analyzing geographic and business-related factors.

The project aims to support better location decisions using data analysis, geospatial visualization, and machine learning techniques.

## Key Features

Business location recommendations

Geographic data analysis

Competitor and nearby facility analysis

Distance-based location evaluation

Interactive map visualization

Machine learning and clustering experiments

## Technologies

Python

Pandas

NumPy

GeoPandas

Scikit-learn

Folium

Matplotlib

## Data

The project uses geographic data stored in GeoPackage (`.gpkg`) format.

The original source of the GeoPackage dataset has not yet been verified. Due to its large size, the file is not included in this repository.

## How to Run

1. Open the Jupyter Notebook in Google Colab.

2. Obtain the required datasets.

3. Update the file paths in the notebook.

4. Run the notebook cells in order.

## Project Scope

Location: Baku, Azerbaijan

Focus: Data Science, Machine Learning, and Geospatial Analysis
